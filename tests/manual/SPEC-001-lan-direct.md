# SPEC-001 局域网直连遥控 — 手工验收清单

- 对应 spec：spec/implemented/SPEC-001-lan-direct.md
- 环境：盒子 H96_Max_V56（Android 12, rooted）+ 三星 Note20（Android 13），同一 WiFi
- 结果标记：P 通过 / F 失败 / N 未执行；执行后填写「实际」与日期
- 自动部分（AC-9）由 tests/protocol/run.ps1 覆盖，本清单只含手工项

## 前置条件

1. `python build.py server` 构建，盒子安装 TVRemoteServer.apk 并打开
2. `python build.py app` 构建，手机安装 TVRemote.apk
3. 手机与盒子在同一局域网，盒子端界面可见配对码
