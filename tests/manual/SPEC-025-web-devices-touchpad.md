## 实测备注

- 登录/配对流程：`#pair=119297` 打开后自动配对、清除 hash、状态「已连接」、设备栏显示 IP。
- 跨源：页面来自 127.0.0.1:9000，API 请求发往 192.168.3.125:17880，CORS 预检与业务请求全部 200。
- 触控板请求顺序：进入触控板发 `MOVE 0 0`；拖动依次 `MCLICK 1`、多段 `MOVE`、`MCLICK 0`；
  单击 `MTAP`；长按 `MLONG`。H96 无障碍关闭时返回 `ERR a11y`，页面提示，不静默失败。
- 旧页面缓存问题已消除：外壳文件改为 `no-store`，SW 安装时 `cache: reload`，缓存版本 v4。
- 待补验：真实第二台盒子、HTTPS 相机扫码、双指滚动、iPhone/HarmonyOS 浏览器。
