# SPEC-027 手工验收清单：启动自动探测更新与「有更新」标签

环境：手机端 App（三星 Note20 / 模拟器均可），可联网访问 GitHub。

## 前置

- 最新 Release 版本需**高于**当前 App `versionName` 才能看到标签。
  若当前已是最新，把 `app/AndroidManifest.xml` 的 `versionName` 临时调低一档构建安装，
  验完再恢复（记录本次临时版本号）。

| 编号 | 步骤 | 预期 | 结果 |
|---|---|---|---|
| AC-1 | 冷启动 App（后台杀掉进程后再打开），观察界面 | 不弹 Toast、界面不卡顿；后台完成一次 Release 请求 | 通过（无 Toast，约 3 秒内标签出现） |
| AC-2 | 当前版本低于最新 Release 时启动 App | 顶栏出现「有更新」标签，滚动到任意位置仍可见 | 通过（临时版本名 1.5.0，最新 v1.5.1） |
| AC-3 | 点击「有更新」标签 | 弹出更新说明 Sheet（版本号、当前版本、说明、「稍后」/「下载并安装」） | 通过（弹出 v1.5.1 说明） |
| AC-4 | 当前版本不低于最新 Release 时启动 App，再手动点「关于」卡「检查更新」 | 启动无标签；手动提示已是最新，标签保持隐藏 | 通过（1.6.0 启动无标签；手动检查走原提示） |
| AC-5 | 切换语言到英文／中文重启 | 英文显示「Update」，中文显示「有更新」 | 待执行（中文字符已验证，英文待看） |
| AC-6 | `python build.py app`；`powershell -File tests\protocol\run.ps1` | 构建通过；协议回归全绿 | 通过（196/196） |
