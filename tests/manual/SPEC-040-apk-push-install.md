# SPEC-040 APK 推送安装 — 手工验收清单

状态：待实现

## 前置条件
- 盒子已安装 TVRemoteServer 并开启无障碍。
- 手机与盒子同一局域网，已配对直连。
- 准备一个测试 APK（任意小体积 APK）和一个 http/https APK 下载链接。

## 验收步骤

| # | 步骤 | 预期结果 | 结果 |
|---|---|---|---|
| 1 | 安卓手机端打开 App，进入直连模式，找到「安装 APK」卡 | 显示「选择文件」和「APK 链接」两个入口 | ☐ |
| 2 | 点「选择文件」，系统文件选择器打开，筛选 APK 文件 | 能选到 .apk 文件 | ☐ |
| 3 | 选中一个 APK，等待上传完成 | 盒子弹出系统安装确认界面 | ☐ |
| 4 | 在「APK 链接」输入框填入有效的 http(s) APK 下载地址，点发送 | 盒子开始下载，完成后弹出安装确认界面 | ☐ |
| 5 | 填入 `ftp://example.com/a.apk` 链接发送 | 手机端提示参数错误，盒子不下载 | ☐ |
| 6 | iOS/鸿蒙浏览器打开网页遥控，在「安装 APK」区填链接发送 | 盒子下载并弹出安装确认 | ☐ |
| 7 | 浏览器点「选择文件」上传一个 APK | 盒子弹出安装确认 | ☐ |
| 8 | 浏览器上传一个非 APK 文件（如 .txt） | 返回 notapk 错误，不安装 | ☐ |
