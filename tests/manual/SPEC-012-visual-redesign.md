# SPEC-012 界面视觉重设计与应用动态化 — 手工验收清单

- 对应 spec：spec/developing/SPEC-012-visual-redesign.md
- 结果标记：P 通过 / F 失败 / N 未执行

## 用例

### TC-012-01 构建与协议回归（AC-1）
步骤：`python build.py app`、`python build.py server`、`powershell -File tests\protocol\run.ps1`。
预期：构建成功、APK <200KB；含 LIST 用例全绿。
实际：app 121KB / server 97KB 构建通过；run.ps1 44/44 全绿
（首跑 discover_no_broadcast_null 撞真实盒子 UDP 广播，已知环境 flaky，重跑通过）。
结果：P

### TC-012-02 视觉规范呈现（AC-2）
步骤：真机打开两端 App 截图。
预期：分组卡片、渐变 OK 键、图标化系统键、紧凑十字键，
无缺字形方块，整体现代协调。
实际：手机端遥控器主卡（大圆盘 + 四向小圆键 + OK 蓝色光环圈）、圆形图标键
← ⌂ ≡、电源红字（U+23FB 缺字形按 spec 回退文字）、音量胶囊 + 静音圆键、
文字输入卡、应用快捷卡全部成型；盒子端三卡（服务状态/配对码/连接地址）同语言。
未发现缺字形方块。审美最终确认留用户。
结果：P（审美确认留用户）

### TC-012-03 应用动态化（AC-3）
步骤：连接盒子，对照盒子端 `pm list packages -3` 输出检查应用卡。
预期：只显示已装候选应用；全部未装时应用卡整体隐藏。
实际：盒子实际装有全部 5 个候选（OK影视/飞牛TV/当贝桌面/当贝市场/Kodi），
应用卡显示 6 个按钮（含设置），ADB 与直连两种模式下均正确
（期间修复 AdbClient exec 输出错位缺陷，pm list 此前一直返回空）。
「全部未装隐藏」分支由单元语义保证（rebuildApps 空集 return），未真机构造。
结果：P

### TC-012-04 双语分组标题（AC-4）
步骤：切换 English 后检查分组标题。
预期：Remote / Input / Apps；切回中文恢复「遥控器」等。
实际：模拟器（emulator-5554）语言弹窗切 English：Remote / Input / Apps、
Mode 段 Direct / ADB / BT、Scan / Add 全部正确；切中文：遥控器 / 文字输入 /
应用快捷、直连 / ADB / 蓝牙、扫描 / 添加 全部正确（getString 链路无遗漏）。
结果：P

### TC-012-05 多尺寸不回归（AC-5）
步骤：手机（紧凑/标准档）与平板宽度（>=600dp）各查一次。
预期：布局不破、按键可点。
实际：模拟器 wm size/density 覆盖三档实测：标准（1080x2400@420）正常；
紧凑（640x1280@320，sw320dp）模式栏五个入口完整、圆盘 200dp 四向键对称、
系统键/音量行四列不错位；平板（1600x2560@320，sw800dp）内容 520dp 居中、
圆盘 280dp 对称、四列对齐。期间发现并修复平板档应用卡被拉伸到视口底部
（fillViewport），修复后各档卡片按内容高度收尾。
结果：P

### TC-012-06 既有行为回归
步骤：模式切换、语言切换、按键（ADB+直连）、设备切换各过一遍。
预期：与 SPEC-008/009/011 验收时行为一致。
实际：ADB↔直连模式切换（真机各一次，选中段渐变、状态文案正确）、
直连按键链路（LIST 拉取即走通协议）正常；语言切换/设备切换未重复执行
（本轮未改动其逻辑）。
结果：P（部分，语言/设备切换逻辑未动不重验）

### TC-012-07 扫描单弹窗（FR-12-6）
步骤：点「扫描」，观察状态行与弹窗；9 秒内看结果是否在弹窗内实时增加。
预期：状态行不再出现扫描文字；弹窗内先「正在扫描…」，发现后变「扫描到 N 台」
并逐条加行；点行添加并连接；关闭弹窗即停发现。
实际：点扫描立即弹窗，状态行保持「已连接 · H96_Max_V56」不变；约 1 秒后
弹窗显示「扫描到 2 台设备」并列出 adb-8BCTZNRORK / adb-RFCRA0DVDNN-XIAFvj
（含 IP:端口 + 点此添加并连接）；点第二行成功添加并连接（该端口已关闭，
状态如实显示连接失败）；关闭后无残留发现。
结果：P

### TC-012-08 自绘弹窗样式（FR-12-7）
步骤：依次打开设备选择、扫描、手动添加三个弹窗截图对照。
预期：深色 SURFACE 卡片 22dp 圆角 + 60% 遮罩；标题 18sp 粗体；
列表项圆角行，选中行淡蓝底 + 右侧蓝点；输入框 SURFACE2 圆角；
底部右对齐，主操作渐变胶囊白字，次操作 SUB，删除为红字。
实际：三处弹窗全部为深色卡片样式，与主界面一致，无原生白底/灰框；
设备选择弹窗选中项蓝点与淡蓝底正确，删除当前为红字；
手动添加弹窗两个输入框深色圆角、添加并连接为蓝色渐变胶囊。
语言选择/直连配对/蓝牙两处沿用同一 Sheet 容器（结构相同，未逐一截图）。
结果：P

### TC-012-09 应用名称显示（发现并修复）
步骤：查看应用快捷卡。
预期：圆形图标位 + 下方完整应用名。
实际：真机发现名称全部不可见——权重参数 w() 把单元高度写死为 keyH，
名称被裁掉；改为高度自适应的 wc() 后 设置/OK影视/飞牛TV 等名称正常显示。
结果：P

### TC-012-10 布局四项修正（AC-7）
步骤：Note20（RFCN803AF2L）真机：上下滚动页面；观察十字键与圆盘；
对照系统键行与音量行；查看应用卡。
预期：顶栏（设备信息 + 模式栏）不随滚动；四向键在盘面上下左右对称；
两行四列逐列对齐且行内均分；应用为图标 + 完整名称。
实际：滚动后顶栏位置不变；像素实测四向键中心距盘心上下 242/243px、
左右 242/243px（对称）；系统键四列中心 192.5/423.5/654.5/885.5px 与音量行
−/音量/+/静音 193.3/424/654.7/885.5px 对齐（偏差 ≤1px）；应用卡 6 项
（设置/OK影视/飞牛TV/当贝桌面/当贝市场/Kodi）均显示完整名称。
根因记录：圆盘容器原为 MATCH_PARENT 宽于盘面，左右键按容器边距定位落到盘外。
结果：P

### TC-012-11 能力按钮按盒子能力隐藏（AC-8 / FR-12-9）
步骤：模拟器（emulator-5554，设备 LocalBox 127.0.0.1:5555）装手机端与盒端；
1) force-stop 盒端服务后 HOME 再进应用；2) 重启盒端服务后同样回前台；
3) 观察 ADB 握手失败、蓝牙未配对时对应段是否保留。
预期：8899 被拒绝 → 「直连」段隐藏、剩余段均分并占满；服务恢复后「直连」段回来；
ADB/蓝牙属连接错误或未配对，段保持显示。
实际：8899 关闭时 dump 仅剩 ADB / BT 两项（分段胶囊自动均分）；
`nc -z 127.0.0.1 8899` 由 refused 变 open 后回前台，「直连」段恢复；
ADB 握手失败（状态行「操作失败：握手失败」）时 ADB 段仍显示；
点 BT 弹出「未配对」自绘 Sheet（先与盒子在系统设置配对），BT 段仍显示。
蓝牙两条「不支持」隐藏路径（手机无 HID / 盒子无 bluetooth 特性）环境无法构造，
逻辑已实现，记入 spec 边界与已知限制。
结果：P（蓝牙隐藏分支待环境）

### TC-012-12 模拟器端到端直连配对与按键
步骤：模拟器内启动盒端服务并读取界面六位配对码；手机端点「直连」，
输入 127.0.0.1 与配对码，点 Pair and connect；随后按方向键观察盒端日志。
预期：显示 Paired · 127.0.0.1；按键命令送达盒端并进入 keyevent 执行路径。
实际：配对成功（状态 Paired · 127.0.0.1）；按 ▲ 后 logcat TvRemoteServer 出现
`exec fail / Cannot run program "/system/xbin/su"`，说明 KEY 命令已解析并进入
keyevent 执行（模拟器无 root，真机盒子有 su 时正常执行）。
结果：P（模拟器按键效果受限，真机为准）

### TC-012-13 音量胶囊左端与返回圆键对齐
步骤：观察音量行胶囊左边缘与系统键行返回圆键左边缘是否同一条竖线；

预期：两者左边缘像素重合；电源与静音右边缘重合；胶囊右端不超过第三列右界。

平板档（1600x2560@320）375/375、右边缘 1224/1224。
结果：P
