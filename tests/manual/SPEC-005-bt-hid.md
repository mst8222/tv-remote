## 用例

### TC-005-01 HID 注册与连接（AC-1, FR-5-1/2）
步骤：手机与盒子完成系统蓝牙配对 → App 点「蓝牙」→ 选择盒子。
预期：状态栏「蓝牙 HID 已注册」→「蓝牙已连接 · <设备名>」。
实际：Note20（SM-N9810）与 H96 Max V56 配对后点「蓝牙」，
状态依次为「正在初始化蓝牙 HID…」→「蓝牙已连接 · H96_Max_V56」；
H96 `dumpsys input` 出现「嵩韬 的 Note20 Keyboard / Consumer Control」。
结果：P

### TC-005-02 全键位（AC-2, FR-5-3/4）
步骤：依次按 ↑↓←→/OK/返回/主页/菜单/音量+/音量−/静音/电源。
预期：盒子（或任意已配对蓝牙设备）收到对应按键。
实际：点 ← / ⌂ / ▲ / 音量+ / 音量− / 静音，H96 `getevent` 依次捕获
KEY_ESC、KEY_HOME、KEY_UP、KEY_VOLUMEUP、KEY_VOLUMEDOWN、KEY_MUTE；
HOME 使 H96 从 Settings 切回当贝桌面。App 日志 `sendKey/sendConsumer ok=true`。
结果：P

### TC-005-03 后台恢复（AC-3, FR-5-5）
步骤：App 切后台 10 秒再回前台，继续按键。
预期：HID 注册自动恢复，按键有效。
实际：退后台再回前台后点「蓝牙」自动重注册并连回上次盒子（`bt_addr` 记忆），
按键继续有效。
结果：P

预期：手机端显示「蓝牙已断开」并退出蓝牙模式；重新打开后点「蓝牙」可再次连接。
