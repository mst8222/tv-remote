# SPEC-033 手工验收清单：盒端界面宽屏双栏与二维码前置

环境：模拟器 Medium_Phone_API_36.1（宽屏 1280x960@240、窄屏 1080x2400@420）；
物理盒子 RK3566 / Fold3 本轮不可达，宽屏真机待复验。

## 验收项

- [x] AC-1 电视/宽屏首屏内可直接看到配对码与完整二维码，无需滚动。
  2026-10-22：宽屏 1280x960@240 截图，左栏服务状态/配对码/版本更新，右栏连接地址含二维码，
  首屏完整可见。
- [x] AC-2 二维码可被识别，内容含当前 IP 与配对码。
  2026-10-22：对宽屏截图执行 `cv2.QRCodeDetector` 解码得到
  `http://10.0.2.15:17880/#pair=915837`（模拟器 IP）。
- [x] AC-3 宽屏左右两栏底边平齐，二维码在连接地址卡内、尺寸与留白协调。
  2026-10-22：截图目视两栏底边对齐；右栏地址卡吸收剩余高度，二维码上方留白、
  下方扫码提示完整。
- [x] AC-4 手机竖屏（<720dp）单列布局，二维码位于连接地址卡内且完整显示。
  2026-10-22：1080x2400@420 截图，配对码 48sp 单行显示，二维码完整。
- [x] AC-5 服务状态、配对码、地址、版本更新、二维码显隐与改动前一致。
  2026-10-22：模拟器上四项内容均正常显示；未联网隐藏场景沿用既有逻辑，未单独复测。

## 验证记录

- 2026-10-22 1.6.8：二维码曾放在配对码卡，右栏地址卡留白过多；用户反馈信息分类错误、
  两栏高度不齐。
- 2026-10-22 1.6.9：二维码回归连接地址卡；`fitColumns()` 首帧后统一两栏总高度，
  剩余高度由配对码卡与地址卡吸收；窄屏配对码改为 48sp 避免六位数字折行。
