## 背景与目标

手机端全部 UI 用代码构建（无 layout XML），提供遥控按键、文字输入、应用快捷、
设备管理与三模式（ADB / 蓝牙 / 直连）分发。

## 功能需求（FR）

- FR-3-1 顶部栏：当前设备名（点击弹设备选择器）、连接状态（绿/红两色文字）、
  模式切换按钮（ADB/蓝牙/直连，点击或长按语义见 FR-3-8、SPEC-001 FR-1-15）、
  「扫描」「添加」入口。
- FR-3-2 遥控键位：方向键（↑↓←→）+ 中央 OK 组成的十字键；
  返回(4)/主页(3)/菜单(82)；音量+(24)/音量−(25)/静音(164)/电源(26)。
  所有按键按当前模式分发（直连 → KEY；蓝牙 → HID 映射；ADB → input keyevent）。
- FR-3-3 文字输入：单行输入框 + 发送按钮；空内容不发送；发送后清空输入框。
- FR-3-4 应用快捷：设置/OK影视/飞牛TV/当贝桌面/当贝市场/Kodi 六个按钮，
  按当前模式分发（直连 → APP；否则 monkey）。
- FR-3-5 设备列表持久化：`{名称|IP|端口}` 多行存 SharedPreferences（`devs`），
  当前设备名存 `cur`；重启 App 后恢复列表与当前选中。
- FR-3-6 默认设备：列表为空时注入两条默认设备（荐片TV RK3566 192.168.3.125:5555、
  三星 Fold3 192.168.3.38:5555）。
- FR-3-7 设备增删切换：选择器点击切换（自动断开旧连接并重连新设备）；「删除当前」
  删除后回到第 0 台；手动添加时按 `IP:端口` 去重，重复添加等价于切换到已有项。
- FR-3-8 模式切换按钮：初始显示「ADB」；点击在 ADB ↔ 蓝牙间切换；
  「直连」按钮独立（点击进入/长按清除配对，见 SPEC-001）。
- FR-3-9 状态反馈：所有网络操作在后台线程执行，结果回 UI 线程更新状态栏；
  异常信息截断到 26 字符以内显示。

## 非功能需求（NFR）

- NFR-3-1 深色主题固定配色（背景 #0B0F14 等），适配电视遥控场景单手操作，
  按键尺寸不小于 48dp 高。
- NFR-3-2 UI 全代码构建，无 XML layout，与手工编译链兼容（SPEC-004）。
- NFR-3-3 网络操作不阻塞主线程；退出时关闭 ADB/蓝牙/线程池与 NSD 发现。

## 验收标准

- AC-1 启动后十字键、返回/主页/菜单、音量/静音/电源、文字输入、六个应用按钮
  全部可见可点。 【手工】
- AC-2 每个按键在三种模式下分别验证有正确反应（直连为主，蓝牙/ADB 按各自 spec）。 【手工】
- AC-3 输入框为空点「发送」无任何请求发出；输入中文/英文/空格混合文本发送后
  输入框被清空。 【手工】
- AC-4 添加设备 → 杀进程重开 → 列表与当前设备保持不变。 【手工】
- AC-5 重复添加相同 IP:端口不会产生两条记录，而是切换到已有条目。 【手工】
- AC-6 删除设备时若仅剩一台，提示「至少保留一个设备」。 【手工】
- AC-7 添加对话框中端口填非数字（或省略）时回落 5555；名称为空时以 IP 作为名称。 【手工】
- AC-8 网络失败（断网/IP 错误）时状态栏红色提示，App 不崩溃。 【手工】

## 边界与已知限制

- 设备名以 `|` 分隔存储，名称中含 `|` 或换行会破坏格式（当前未转义，
  输入端为自由文本 —— 记录为已知限制）。
- 蓝牙模式为实验性（SPEC-005 未打通），切到蓝牙后按键暂无实际效果。
- 状态栏异常信息截断 26 字符，长错误（如堆栈类消息）可能显示不全。
- Dialog 内的 EditText 未做输入长度上限限制。
