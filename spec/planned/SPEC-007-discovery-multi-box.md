# SPEC-007 直连设备发现与多盒子管理

## 变更记录

## 背景与目标

v1.0 直连模式只支持一个盒子：`lanHost`/`lanToken` 是单条持久化，换盒子必须
长按清除重新配对；「自动发现」也只是回填配对框，不进设备列表。
家里有多台盒子（客厅/卧室）时应能像 ADB 模式一样管理和切换。

## 功能需求（FR）

- FR-7-1 直连设备表：直连设备复用 ADB 设备列表的存储与选择器交互
  （每项含 名称/IP/端口/直连token），在设备选择器中统一展示与切换。
- FR-7-2 发现入列表：「自动发现」持续监听 UDP 8898，把所有 `TVREMOTE|`
  广播的盒子（按 IP 去重，展示 Build.MODEL 名称）列成可点选列表；
  点击已配对的盒子直接连，未配对的进入配对流程。
- FR-7-3 配对绑定到设备：配对成功后 token 与该设备条目绑定持久化，
  切换设备无需重新配对。
- FR-7-4 状态显示：顶部状态栏显示当前直连设备名与 IP；未配对的盒子在列表中
  标注「未配对」。
- FR-7-5 兼容升级：无老版本数据迁移负担（无历史用户），直接采用新存储结构，
  旧 `lanHost`/`lanToken` 键一次性移除。

## 非功能需求（NFR）

- NFR-7-1 发现监听最长 10 秒自动停止，期间不阻塞 UI。
- NFR-7-2 切换设备端到端（点选→状态栏显示已连接）不超过 2 秒（已配对时）。
- NFR-7-3 设备表持久化格式向后兼容 ADB 设备列表（同一存储，不分裂成两套）。

## 验收标准

- AC-1 两台盒子分别配对后，选择器中两条直连设备可随意切换，均无需重新配对。 【手工】
- AC-2 「自动发现」能列出所有在运行的盒子（含未配对标注），点击未配对盒子
  直接进入配对。 【手工】
- AC-3 杀进程重开后直连设备列表与各自的配对状态保持。 【手工】
- AC-4 自动测试：MockBoxServer 两条广播（不同 IP）在 10 秒内都被发现且去重。 【自动】

## 边界与已知限制

- 同一盒子的 IP 变化（DHCP）后视为新设备（按 IP 去重），旧条目残留需手动删除；
  是否引入按 MAC/名称合并，实现时再定，不做过度设计。
- 发现依赖广播可达（同网段、无 AP 隔离）。
