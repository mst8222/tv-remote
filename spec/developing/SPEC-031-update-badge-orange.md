# SPEC-031 「有更新」标签橘色背景

## 元信息

- 状态：developing
- 创建：2026-10-22
- 更新：2026-10-22（开工）
- 优先级：low

## 变更记录

- 2026-10-22 创建并开工：用户反馈顶栏「有更新」标签沿用蓝色强调色，
  与遥控器按钮混在一起不够醒目，要求改为橘色背景。仅调整该标签配色。
- 2026-10-22 实现完成：`BADGE = 0xFFF07A1A`，标签背景改用该色；版本升至 1.6.7
  （versionCode 11）。GitHub 与 Gitee 均已发布 v1.6.7 并上传双端 APK，
  Gitee 匿名下载 SHA-256 与本地一致；H96 已安装盒端 1.6.7。
  手机端需安装 1.6.7 后截图确认橘色效果（AC-1~4）。

## 背景与目标

「有更新」标签是唯一表示「有新版本可升级」的状态提示，当前使用与方向盘、
OK 键相同的蓝色（`0xFF4F7CFF`），在深色界面里与主操作色混淆。
改为橘色背景，白色文字，形状与尺寸保持不变，其余配色不动。

## 功能需求（FR）

- FR-31-1 「有更新」标签背景改为橘色 `0xFFF07A1A`，文字保持白色。
- FR-31-2 圆角胶囊形状、内边距、字号、位置与点击行为不变。
- FR-31-3 其他控件配色（蓝色强调、电源红字、状态绿点）不变。

## 非功能需求（NFR）

- NFR-31-1 白字在橘色背景上的对比度满足小字号可读要求。
- NFR-31-2 仅手机端顶栏存在该标签，盒子端与网页端无同元素，不做改动。

## 验收标准

- [ ] AC-1 顶栏出现「有更新」时背景为橘色，文字清晰可读。
- [ ] AC-2 标签为圆角胶囊，尺寸与位置和改动前一致。
- [ ] AC-3 点击标签仍能打开更新说明。
- [ ] AC-4 方向盘、OK 键、电源、状态点等其他颜色未变化。

## 边界与已知限制

- 深色背景下橘色饱和度高，避免再叠加透明度导致发灰。
- 只改颜色常量，不引入主题化或用户可选配色。
