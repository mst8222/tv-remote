# SPEC-013 移除手机端 ADB 控制方案

## 元信息
- 状态：developing
- 创建：2026-10-21
- 更新：2026-10-21
- 优先级：high

## 变更记录
- 2026-10-21 创建：用户明确要求去掉手机侧全部 ADB 控制方案，只保留直连与蓝牙
- 2026-10-21 调整 FR-13-7：按用户要求取消按钮隐藏，两段模式按钮常显；
  连接失败仅提示原因。真机验证中修复：进入蓝牙模式未清 lanMode 导致按键
  仍发往直连目标；蓝牙回调误将 CONNECTING 当作断开导致模式标记丢失。

## 背景与目标

手机端原有三种控制模式：直连（盒子端服务）、ADB（无线调试）、蓝牙 HID。
实际使用中 ADB 模式依赖盒子开启无线调试并在首次连接时人工确认公钥，
在 Android 13 的三星 Fold3 上因 adbd 不接受 App 内置公钥而无法握手；
同时 ADB 设备发现（mDNS `_adb._tcp`）与设备表端口（5555）也让界面和
设备管理复杂化。

目标：彻底移除手机侧 ADB 控制方案，把界面、设备管理、扫描全部收敛到
「直连 + 蓝牙」两种可控路径，并保证这两条路径可用、报错清晰。

## 功能需求（FR）

- FR-13-1 删除手机端 ADB 客户端与密钥：`AdbClient.java`、`KeyConst.java`
  以及构建期 `keys/adbkey.pk8 → KeyConst.java` 的生成逻辑全部移除；
  构建不再要求 ADB 私钥。
- FR-13-2 模式栏只保留「直连」「蓝牙」两段并等分；不再出现 ADB 段。
- FR-13-3 启动时不发起任何 ADB 连接：当前设备已配对则直接进入直连，
  未配对则状态栏提示「还没配对，点直连开始」。
- FR-13-4 设备表只保存 `名称|IP`；直连端口固定 8899；读取旧版
  `名称|IP|端口` 数据时忽略端口，不报错。
- FR-13-5 「扫描」改为监听盒子 UDP 8898 广播（`TVREMOTE|端口|名称`），
  收集多台设备并展示，点击后添加设备并弹出配对框；不再使用 mDNS
  发现 `_adb._tcp` / `_adb-tls-connect._tcp`。
- FR-13-6 文字发送与应用打开只走直连；在蓝牙模式或未选模式时给出
  「该功能需要直连」的明确提示，不静默失败。
- FR-13-7 模式按钮不隐藏：「直连」「蓝牙」两段始终可见可点；
  连接失败只用状态栏与弹窗说明原因（直连端口拒绝、蓝牙未注册等），
  不再做能力探测与按钮显隐。用户明确要求：没装盒端服务自然连不上直连，
  隐藏按钮没有必要。
- FR-13-8 触摸按键分发只保留两路：直连 → `KEY`；蓝牙 → HID 报告；
  未选模式时提示先选模式。

## 非功能需求（NFR）

- NFR-13-1 不引入第三方依赖；APK 体积不因本次改动增加。
- NFR-13-2 直连保持每命令短连接（SPEC-011），蓝牙按键端到端延迟
  与人手感知一致（< 150ms）。
- NFR-13-3 所有移除后的路径错误文案仍满足 SPEC-008 的「发生了什么 + 怎么办」。

## 验收标准

- AC-1 手机端源码与构建脚本中不再引用 `AdbClient` / `KeyConst` / ADB 握手；
  `tools/AdbTest.java` 作为 PC 端调试原型可保留。 【自动：grep】
- AC-2 模式栏只有「直连」「蓝牙」两段，点击切换与高亮正确。 【手工】
- AC-3 已配对设备冷启动直接进入直连；未配对时提示配对。 【手工】
- AC-4 点「扫描」能发现运行盒子端服务的设备（H96 / Fold3），点击后
  添加并可完成配对。 【手工】
- AC-5 蓝牙模式下点「发送」或应用快捷，状态栏给出「需要直连」提示，
  不崩溃、不影响后续按键。 【手工】
- AC-6 H96 Max（有 root）直连全命令通过：PAIR / KEY / TEXT / APP / LIST / PING。 【手工】
- AC-7 Fold3（无 root）直连按键返回 `ERR exec`，手机提示盒子执行失败
  （root 说明），不出现假成功。 【手工】
- AC-8 `python build.py app` 构建通过，`tests\protocol\run.ps1` 全绿。 【自动】

## 边界与已知限制

- 直连依赖盒子端 root：Fold3 未 root，直连无法注入按键，只能用蓝牙 HID。
- 扫描依赖 UDP 广播；路由器开启 AP 隔离或不同网段时扫描不到，可手工添加 IP。
- 蓝牙 HID 受系统限制：App 退后台会注销注册，回前台需重新注册（见 SPEC-005）。
