## 背景与目标
蓝牙 HID 模式要求手机与盒子先完成系统蓝牙配对。现有界面只显示已配对设备，
未配对时仅提示「让盒子搜索这台手机」，用户需要离开 App 到系统设置里操作，路径长且不易理解。
目标是在蓝牙设备选择弹窗中提供「扫描附近蓝牙设备」，由手机主动发现盒子并发起配对。

## 功能需求（FR）
- FR-037-1 蓝牙设备选择弹窗提供「扫描附近蓝牙设备」动作（有/无已配对设备时都可用）。
- FR-037-2 扫描前检查手机蓝牙开关：未开启时弹系统开启请求，开启后继续扫描。
- FR-037-3 扫描前检查定位权限（旧蓝牙权限模型下发现设备需要）：无权限时请求；
  拒绝后提示需要位置权限。
- FR-037-4 扫描结果按地址去重列出，显示设备名（空则地址）、地址与已配对/未配对标记。
- FR-037-5 点击已配对设备：记录为该盒子的蓝牙目标并连接。
- FR-037-6 点击未配对设备：调用系统配对（createBond）；配对成功自动连接并记录目标；
  配对失败/取消时提示失败原因与重试建议。
- FR-037-7 扫描弹窗关闭、扫描结束或界面销毁时停止扫描并反注册广播接收器。
- FR-037-8 无扫描结果时提示确认盒子蓝牙已打开且可被发现。

## 非功能需求（NFR）

## 验收标准
- AC-1 蓝牙设备选择弹窗出现「扫描附近蓝牙设备」。
- AC-2 盒子蓝牙可发现时，扫描列表出现该盒子；点击未配对设备可在盒子端确认配对码并完成配对。
- AC-3 配对成功后自动连接，按键可用；状态显示已连接。
- AC-4 配对取消/失败时提示正确，可重新扫描重试。
- AC-5 未授予定位权限时提示需要位置权限；授权后可正常扫描。
- AC-6 `python build.py app` 构建成功，协议回归 `tests\protocol\run.ps1` 0 失败。

## 边界与已知限制
- 盒子必须处于可被发现状态（打开蓝牙设置页/配对模式），否则扫描不到。
- 扫描受系统 12 秒窗口限制，扫描结束需重试。
- 部分电视固件在配对后不会自动建立 HID 连接，仍需点一次设备连接（沿用既有行为）。
- 不处理既有 HID 描述符缓存问题（见 README 已知限制）。
